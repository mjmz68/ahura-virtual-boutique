# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

For a private report, contact the repository owner through GitHub or use a private GitHub Security Advisory. Include the affected URL or file, the impact, and concise reproduction steps.

## Operational guidance

- Never commit GitHub tokens, passwords, customer data, or private order details.
- Use a fine-grained token limited to this repository and the minimum required Contents permission.
- Revoke and replace a token immediately if it may have been exposed.
- Keep two-factor authentication enabled on the GitHub account.
